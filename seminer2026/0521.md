## 意味の定量表現（単語埋め込み）
テキストを定量的に比較したいというモチベーションは昔からあった
- 例えば単語出現頻度

ただこのアプローチには問題がある
- 意味的には同じだけど違う単語を別単語としてカウントしてしまう
- もっと意味的に分類したい　意味を定量的に扱いたい

シソーラス：階層構造（樹形図的な）で意味の類似性を把握する、というモチベーション
- コストが高く、細かなニュアンスまでは表現できない

Glove：付近に存在（共起）している単語が近しい単語は意味も近いはずだ、というモチベーション
- 次元が多すぎる
- 計算コストが大きい（全コーパスから一つの共起行列を作るため）
- 「が」「に」などの機能語が現れすぎる

概要
1. 入力は「論文題目」
sample.py は sample.csv の3列目を対象にしている。今回のデータでは、3列目は論文題目である。

例:
湖沼・内湾堆積物を用いた南西日本の小氷期イベントの発現パターンとその要因  
植物起源揮発性有機化合物放出量の土壌水分依存性を枝エンクロージャー法/オゾン反応性測定によって把握する試み  
年下の子どもへの教示をめぐる幼児間の相互作用
問い「似た研究テーマの題目は近くに集まるだろうか」
ただし、文字列のままだと足し算、距離、平均などの計算ができない。そこで文章をベクトルに変換する。
2. 文埋め込みとは何か
文埋め込みとは、1つの文や短い文章を、数百次元程度の数値ベクトルに変換したものである。
直感的には、次のような対応を作る。
"年下の子どもへの教示をめぐる幼児間の相互作用"
 -> [0.12, -0.03, 0.44, ..., 0.07]
 ※ |v| = 1に正解正規化されている。
大事なのは、単に文字を数値に置き換えるのではなく、「意味が近い文章ほど、ベクトル空間でも近くなる」ように学習されている点である。
sample.py では、paraphrase-multilingual-MiniLM-L12-v2 という Sentence-BERT 系のモデルを使っている。Hugging Face のモデルカードでは、このモデルは文や段落を384次元の密なベクトル空間に写像し、クラスタリングや意味検索に使えると説明されている。
参照: Hugging Face model card: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
3. ベクトル類似度
 ベクトルの内積 = con類似度
cos(u, v) = (u dot v) / (||u|| ||v||)
※ cos距離 := 1.0 - cos類似度
4. 階層クラスタリング
1. テキスト s1 == (テキスト埋め込み) ==> x1
x1 -> e1 = [0.8, 0.6]
x2 -> e2 = [0.7, 0.7]
x3 -> e3 = [0.1, 1.0]

2. ベクトル同士の比較
e1 = [0.8, 0.6]
e2 = [0.7, 0.7]

cos(e1, e2) = (e1・e2) / (||e1|| ||e2||) ~ 0.990  
cos(e1, e3) = (e1・e3) / (||e1|| ||e3||) ~ 0.677

3. cos距離に変換
コサイン距離 = 1 - コサイン類似度
d(e1, e2) = 0.010
d(e1, e3) = 0.323

つまり、e1, e2が一つのグループになる
memo:
クラス同士の比較は
~~~
avg(
  d(e1,e3),
  d(e1,e4),
  d(e2,e3),
  d(e2,e4)
)
~~~
